# The paper

The same text in three formats, as published on [averroeslabs.org](https://averroeslabs.org/blog/many-agents-few-projects/):

- [`many-agents-few-projects.pdf`](many-agents-few-projects.pdf): the paper, typeset in LaTeX.
- [`many-agents-few-projects/`](many-agents-few-projects/): the web page (`index.html`) and its figures.
- [`many-agents-few-projects.md`](many-agents-few-projects.md): the Markdown version, with figures in the folder above.
- [`latex/`](latex/): the LaTeX source (`paper.tex`, `refs.bib`, `paper.bbl`). Compile it from this folder with `tectonic paper.tex` or `pdflatex` and `bibtex`. It reads the figures from the repository's `figures/` folder.
